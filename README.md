# CampusFixAI

A complete hackathon-ready campus complaint management MVP.

## Features

- Student login
- Admin login
- Complaint submission
- Manual building/room/location
- Optional complaint image
- AI-style category and priority detection
- Complaint IDs
- Student complaint history
- Complaint tracking
- Admin dashboard
- Search and filters
- Status updates
- Staff assignment
- LocalStorage persistence
- Responsive UI
